# Supabase setup

No Supabase project has been selected for MADURA STORE yet. Do not apply the migration to an unrelated project.

1. Select or create a dedicated project for this app.
2. Set VITE_SUPABASE_URL and VITE_SUPABASE_PUBLISHABLE_KEY.
3. Review supabase/migrations/001_madura_store.sql.
4. Apply to a development project first.
5. Verify RLS and run security/performance advisors.
6. Configure deployment environment.

Never expose service-role or secret keys in frontend code.
